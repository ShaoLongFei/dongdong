# Mem0 Memory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add persistent Mem0-backed memory to dongdong and expose it to Linx through the existing MCP tools.

**Architecture:** Run Mem0's Python SDK inside the Mac device process. Store Qdrant vectors and SQLite history under the repository's ignored `.memory/` directory; use OpenAI for extraction and embeddings; register search, save, list, and ID-scoped delete through `tools.py`.

**Tech Stack:** Python 3.12, `mem0ai` OSS SDK, local Qdrant, SQLite, OpenAI API, existing MCP registry and `tests/smoke.py`.

**Spec:** `docs/superpowers/specs/2026-10-24-mem0-memory-design.md`

## Global Constraints

- Keep Qdrant at `.memory/qdrant/` and Mem0 history at `.memory/history.db`; ignore `.memory/` in Git.
- Read OpenAI credentials from `OPENAI_API_KEY`; never write credentials or memory text to logs.
- Do not persist raw audio or full conversation transcripts.
- Expose only ID-scoped deletion; do not register `delete_all`.
- If the resolved install download exceeds 20 MB, stop before installation and ask the user for approval.
- Follow `AGENTS.md`: no TDD, one assert-based smoke check for the deletion boundary, files under 300 lines, and `./scripts/check.sh` before each commit.

## Review Focus

- Empty or whitespace-only search/save input must fail before making an API request; smoke-test argument validation.
- Empty, blank, or foreign memory IDs must not delete data; smoke-test empty-ID rejection and verify a real deletion only affects the listed user's record.
- A missing `OPENAI_API_KEY` must produce an actionable error without breaking `dongdong tools`; manually check both commands.
- Restarting from a different current directory must still use the repository's `.memory/` paths; verify resolved paths and a saved memory after restart.
- Search/list must always filter by the stable device ID; verify returned records belong to the configured `user_id`.

### Task 1: Add the Mem0 adapter and durable local storage

**Files:**
- Modify: `apps/device-mac/pyproject.toml`
- Create: `apps/device-mac/dongdong/memory.py`
- Modify: `.gitignore`

**Interfaces:**
- `memory.search(query: str, user_id: str) -> list[dict]`
- `memory.save(text: str, user_id: str) -> dict`
- `memory.list_(user_id: str) -> list[dict]`
- `memory.delete(memory_ids: list[str], user_id: str) -> list[str]`
- Build the SDK lazily so `dongdong tools` works without an API key.

- [ ] **Step 1: Measure the resolved package download without installing it**

Run:

```bash
mkdir -p /tmp/dongdong-mem0-wheels
.venv/bin/python -m pip download --dest /tmp/dongdong-mem0-wheels 'mem0ai>=2.2.1,<3'
du -sh /tmp/dongdong-mem0-wheels
```

If the total exceeds 20 MB, stop here and ask the user before installing. If it is at most 20 MB, continue.

- [ ] **Step 2: Add the SDK dependency and ignore runtime data**

Add `mem0ai>=2.2.1,<3` to `apps/device-mac/pyproject.toml` and `.memory/` to `.gitignore`. Install the declared project dependencies with `uv pip install --python .venv/bin/python -e apps/device-mac` only after Step 1 passes its size gate.

- [ ] **Step 3: Create `memory.py` with repository-root storage and lazy SDK setup**

Resolve the repository root from `Path(__file__).resolve().parents[3]`; create `.memory/` with owner-only permissions. Construct `Memory.from_config` with Qdrant `path` set to `.memory/qdrant`, `history_db_path` set to `.memory/history.db`, and the documented OpenAI LLM/embedder defaults. Read `OPENAI_API_KEY` from the environment and raise a clear error if it is missing. Keep the SDK instance cached for the process lifetime.

Create the client with this configuration, using the OpenAI key from the process environment:

```python
{
    "vector_store": {
        "provider": "qdrant",
        "config": {"path": str(DATA_DIR / "qdrant"), "collection_name": "dongdong"},
    },
    "history_db_path": str(DATA_DIR / "history.db"),
    "llm": {"provider": "openai", "config": {"model": "gpt-5-mini"}},
    "embedder": {
        "provider": "openai",
        "config": {"model": "text-embedding-3-small"},
    },
}
```

Create `DATA_DIR` with `Path.mkdir(parents=True, exist_ok=True, mode=0o700)`. Implement `search` using `Memory.search(query, top_k=5, filters={"user_id": user_id})`, `save` using `Memory.add(text, user_id=user_id, infer=True)`, and `list_` using `Memory.get_all(filters={"user_id": user_id}, top_k=100)`. Reject empty search and save text before initializing the SDK.

- [ ] **Step 4: Implement ID-scoped deletion**

Reject an empty list or blank IDs. Before deleting, call `Memory.get(memory_id=id)` for every requested ID and verify each record exists and has the requested `user_id`; reject the whole request if any ID is missing or belongs to another user. Then call `Memory.delete(memory_id=id)` for each validated ID and return the deleted IDs. Do not call `delete_all`.

- [ ] **Step 5: Run the existing project checks and commit**

Run `./scripts/check.sh`, then `git diff --check`. Commit the adapter, dependency, and ignore rule as `feat: add local Mem0 memory adapter`; run `git pull --rebase` and push as required by `AGENTS.md`.

### Task 2: Expose memory through MCP

**Files:**
- Modify: `apps/device-mac/dongdong/tools.py`
- Modify: `tests/smoke.py`

**Interfaces:**
- Register `self.memory.search` with required string `query`.
- Register `self.memory.save` with required string `text`.
- Register `self.memory.list` with no required arguments.
- Register `self.memory.delete` with required array `memory_ids` of strings.
- Every operation gets `user_id` from `config.load()["device_id"]`.

- [ ] **Step 1: Register the four memory tools**

Follow the existing `@tool` pattern. Format search results as concise text containing memory IDs and content; format save/list/delete responses so the model can tell whether the operation succeeded. Tool descriptions must instruct the model to save explicit requests, stable preferences, and durable project facts; skip transient requests, passwords, tokens, and credentials. Search results should be limited to five.

- [ ] **Step 2: Add the deletion-boundary smoke assertion**

Add one test to `tests/smoke.py` that calls `tools.call("self.memory.delete", {"memory_ids": []})`, plus calls to `self.memory.search` with an empty query and `self.memory.save` with whitespace-only text. Assert all return `isError: true` and confirm the SDK initializer is not called. Do not add a live API dependency or mock OpenAI/Qdrant.

- [ ] **Step 3: Verify registry, dispatch, and commit**

Run `./scripts/check.sh`; confirm the existing registry test and `mcp.handle(tools/list)` expose all four names. Commit as `feat: expose persistent memory MCP tools`; run `git pull --rebase` and push.
